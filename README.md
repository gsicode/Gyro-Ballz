# Gyro Ballz

A full-screen mobile-friendly web game where you tilt your phone to move silver balls into random shallow dips.

## How to play

- Open `index.html` in a browser.
- Tap the start button.
- Allow motion/gyro permission on mobile when requested.
- Tilt your phone to roll the balls into dips.
- Any dip works.
- A ball can be knocked loose by a hard tilt or by another ball.
- Win when all 5 balls are in the dips.
